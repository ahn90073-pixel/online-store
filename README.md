# online-store — واجهة سوق اون لاين

واجهة المتجر العامة مبنية بـReact وVite، وتعرض المنتجات النشطة والمعتمدة من المستأجرين في [Tagerbackend](https://github.com/ahn90073-pixel/tagerbackend). لا تعتمد قائمة المتجر أو checkout على منتجات mock ثابتة؛ السلة تحفظها محليًا في المتصفح.

## جلب المنتجات

تُحمّل الواجهة الكتالوج العام من `GET /api/storefront/products`، ويتضمن المنتجات النشطة فقط مع اسم الشركة والسعر والعملة والمخزون والتصنيف والصورة. البحث والتصنيفات والعروض تستخدم بيانات الـAPI نفسها. تُعطّل الواجهة الإضافة للسلة إذا كان المخزون صفرًا.

العنوان الافتراضي هو:

```env
VITE_STORE_API_BASE_URL=https://tagerbackend.ahn90073.workers.dev/api/storefront
```

عند تشغيل نسخة محلية، انسخ `.env.example` إلى `.env.local` وعدّل عنوان الـAPI إذا كنت تستخدم Worker أو بيئة اختبار أخرى. متغير `VITE_*` عام داخل حزمة الويب ولا يوضع فيه أي سر.

## إتمام الشراء

لا يتطلب checkout تسجيل دخول. يرسل زر **تأكيد الشراء** اسم العميل وهاتفه والبريد الاختياري وعنوان التوصيل وملاحظاته، إضافة إلى `vendorId` و`productId` والكمية لكل عنصر، إلى `POST /api/storefront/checkout`.

يتحقق Backend من الأسعار والمخزون من قاعدة البيانات (لا يثق بقيم السعر المرسلة من المتصفح)، ويحجز المخزون داخل transaction ذرّية واحدة. ينشئ طلبًا بحالة `pending` لكل تاجر في مجموعته الخاصة، ويحفظ بيانات العميل والعنوان وعناصر الطلب وصورة تفاصيل الشحن في schema ذلك التاجر. السلة متعددة التجار تنتج رقم طلب مستقلًا لكل تاجر. checkout يقبل حتى 50 منتجًا مختلفًا و99 قطعة لكل منتج. الدفع الافتراضي هو عند الاستلام؛ لا يجري هذا الكود أي خصم إلكتروني.

تظهر الطلبات في صفحة **طلبات المتجر** في تطبيق Mange، ومع كل طلب التاجر الذي تنتمي إليه تفاصيل المنتجات. يمكن للإدارة نسخ ملخص الطلب وإرساله للتاجر يدويًا، وتغيير الحالة وإدخال اسم شركة الشحن ورقم التتبع ورسوم الشحن. **لا يوجد تكامل آلي مع مزود شحن أو إرسال تلقائي للتاجر** في هذه النسخة.

> لوحة Mange وAPI الإدارة عامتان بلا مصادقة وفق طلب مالك المشروع السابق؛ لذلك يمكن لأي شخص الوصول إلى بيانات الطلبات والعملاء. لا تجمع بيانات حقيقية في هذا الوضع ما لم يكن كشفها للعامة مقصودًا.

## تشغيل وفحص الواجهة

```bash
npm ci
cp .env.example .env.local
npm run dev
```

```bash
npm run lint
npm run typecheck
npm run build
```

يستخدم المشروع Firebase أيضًا لبعض مكونات الإشعارات المتبقية، لكنه لم يعد يستخدم Firebase لحفظ السلة أو تسجيل checkout.
